## 6. Traps that cost time in this session, so you do not repeat them

1. **Never `2>&1` an `az` call under `EAP=Stop`.** A stderr warning becomes a
   terminating error and kills the harness. It cost one run here.
2. **`az` on Windows is `az.cmd`.** Use `--scripts "@<WINDOWS path>"`; an MSYS
   `/tmp/...` path fails with a parser error.
3. **In Git Bash double quotes, `\$n` collapses to a literal `$n` and eats the
   backslash.** A staging script wrote three downloads to one file `C:\cfv$n`, and
   every size check passed because it measured the file it had just written.
   `FETCH_OK` printed while nothing was staged.
4. **`/mnt/c` is ABSENT BY DESIGN** (`automount enabled=false`). Any probe needing it
   only works on a broken install. Use the `\\wsl$` 9p file channel.
5. **`run-command` runs as SYSTEM and cannot see the WSL distro.** Every WSL probe
   needs the interactive session and the on-VM runner.
6. **`clawfactory-toolchain.sh --list-hosts` prints all 8 hosts on ONE line.** Split
   on whitespace or you will capture one token and report total drift.
7. **A process check that greps for a script name will match its own command line.**
   Exclude `$PID`.
8. **The real install log is `C:\ProgramData\ClawFactory\install.log`** — there is no
   `logs\` subdirectory.
9. **Do not raise a signing-certificate expiry alarm.** Azure Trusted Signing mints a
   fresh 3-day cert daily; a `NotAfter` a day out is normal. I raised this false
   alarm and had to retract it.
10. **Deallocate the VM at every human handoff.** One VM once ran 64 hours for
    nothing.
