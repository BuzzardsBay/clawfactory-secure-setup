## The new blocker — root cause (confirmed from source) + the one-line fix
`resources/freeze-injected-soul.sh` runs as **root** and (line ~27) does:
```
mkdir -p /home/clawuser/.openclaw/workspace /etc/clawfactory
```
OpenClaw creates the workspace **lazily on first turn**, so when the freeze runs first, **root**
creates `/home/clawuser/.openclaw/workspace` **root-owned**. It then chowns only `SOUL.md`
(root:root 444 +i). The **directory** stays root-owned, so when the agent (clawuser) later runs and
tries to create/open `AGENTS.md` there, it gets EACCES and cannot start.

**Fix (next job):** after the `mkdir -p`, `chown clawuser:clawuser /home/clawuser/.openclaw/workspace`
(the directory — and `.openclaw` if the freeze created it too), keeping only `SOUL.md` root-owned +
immutable. Then re-run this validation (probe now de-noised) → the positive control passes → the
**headline finally proves** and B4.3/B4.4 + T6.1-6.3 (proxy gating with a real reply) become valid.
